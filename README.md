# CS Fundamentals

Meu estudo de Ciência da Computação a partir dos primeiros princípios: do transistor ao banco de dados.

## Método
- Poucas horas por semana, todo semana.
- No máximo 2 módulos em andamento ao mesmo tempo.
- Cada tópico termina com uma explicação nas minhas palavras e, quando possível, código escrito do zero.
